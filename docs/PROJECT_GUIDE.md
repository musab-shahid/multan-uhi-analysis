# Spatiotemporal Analysis of Urban Heat Island Effect in Multan, Pakistan (2013–2023): reader guide

1. Read [the original FYP report](../FYP_Multan_UHI_Report.pdf) for the full research narrative.
2. Use [the current results brief](RESEARCH_RESULTS.pdf) and [readable version](RESEARCH_RESULTS.md) for the checked numerical presentation and neutral cluster profiles.
3. Explore [release figures and tables](../results/release/) and [the executed offline notebook](../notebooks/UHI_Results_From_Saved_Tables.ipynb).
4. Follow [the run guide](REPRODUCING_RECONSTRUCTION.md) for offline reproduction or a new Earth Engine extraction.

The original report, poster, historical code PDF, saved execution snapshot and four source CSVs remain preserved. The later 2026 surface proxy is a different model from the original FYP vulnerability calculation. Technical reconciliation belongs in the supporting methods, not the main research narrative.

The Drive working archive contains a 2026_Research_Results_Release folder with the current brief and release package. Original data paths and access permissions are retained. The public website and repository provide reader access separately from Drive.
